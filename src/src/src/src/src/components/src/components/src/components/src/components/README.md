# 🥋 Muay Thai Personal Trainer App

Eine vollständig angepasste Web-App zur Generierung personalisierter Muay Thai Trainingspläne basierend auf deinen körperlichen Daten und Vorlieben.

## Features

✅ **Benutzerprofil-Erfassung**
- Körperdaten (Gewicht, Größe, Alter)
- Erfahrungslevel (Anfänger, Fortgeschrittener, Profi)
- Trainingsziele
- Verletzungshistorie

✅ **Intelligente Trainingsplan-Generierung**
- Automatische Anpassung nach Erfahrungslevel
- Schwierigkeitsstafflung
- Personalisierte Fokusgebiete
- 8-Wochen Trainingsprogramm

✅ **Detaillierte Übungen**
- Aufwärmung
- Haupttraining mit Fokus auf:
  - Footwork & Bewegung
  - Pad Work
  - Clinch Techniken
  - Kraft & Kondition
  - Sparring Vorbereitung
- Cool Down & Dehnen

✅ **Muay Thai Tipps**
- Technik-Tipps
- Ernährungsratschläge
- Verletzungsprävention
- Kraft- und Ausdauer-Entwicklung

✅ **Benutzerfreundliche Oberfläche**
- Responsive Design
- Dunkles Theme (authentisch für Muay Thai)
- Einfache Navigation
- Druckbare Trainingspläne
